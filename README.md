# Nickname Generator

A simple Python program that creates a nickname from three parts:
- your nickname
- any word you choose
- a random number between 10 and 1000

## How it works
1. The program asks for your nickname.
2. Then it asks for any word.
3. It generates a random number from 10 to 1000.
4. It combines everything into one string and prints the result.
